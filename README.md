# 墨序 · SupaAiMd

个人使用的 AI Markdown 笔记网站。Next.js + TypeScript，CodeMirror 编辑，React Flow + ELK 展示只读关系图。

当前版本 **V1.0.10**（对应 `package.json` 的 `version`，界面左下角显示）。每次发布更新末位递增：V1.0.11、V1.0.12……

## 启动

需要 Node.js 20.9 或更高版本。

```sh
npm install
cp .env.example .env.local
# 在 .env.local 填写 DEEPSEEK_API_KEY
npm run dev
```

打开 http://127.0.0.1:3000。密钥只在服务端使用，`.env.local` 不进入 Git。

## 功能

- 真实文件夹和 `.md` 文件；新建、搜索文件名、重命名、移动、导入、导出。
- Markdown 编辑和阅读模式，停止输入 700ms 后保存；保存冲突时保留编辑器内容。
- 和 AI 聊天：AI 读过当前这篇笔记的正文，可以问它内容、结构、说法上的问题，它只讨论，不改写你的文字。
- 按正文生成卡片及连接关系，可平移缩放，禁止编辑与拖动节点。
- 关系图保存到磁盘；正文更新后提示重新生成。
- 删除移入回收站：侧栏「回收站」列出删掉的笔记和文件夹（带删除时间和原位置），可以恢复或彻底删除；服务器不会自动清理。

## 持久化

`NOTES_DIR` 默认为 `./data`，可改为服务器绝对路径。正文按文件夹保存，`.app` 保存关系图、恢复版本及回收内容。备份应包含整个目录。不要把笔记放入 Git；默认已忽略 `data/`。

本版本以单个网站进程为使用前提。文件写入使用临时文件替换，附带正文哈希冲突校验。不适合多个实例同时写同一目录。浏览器关闭前有未保存内容会提醒；尚未提供离线编辑或跨设备实时协作。

## 生产部署

```sh
npm run build
npm start
```

默认仅监听本机地址，适合放在 HTTPS 反向代理之后。对外访问时在 `.env.local` 设置足够长的 `APP_PASSWORD`，所有笔记接口会要求登录。当前为个人共享访问密码，不是多用户账号系统。不要无密码暴露到公网。

密码是唯一的登录凭据，所以登录接口带失败的次数限制：同一来源连续输错 5 次密码就锁定 5 小时，锁定期内即使密码正确也不放行。来源地址优先取反代写入的 `x-real-ip`，其次取 `x-forwarded-for` 的最后一段；没有反代时归到同一个 `unknown` 记录。错误记录写在笔记目录的 `.app/login-guard.json`，删除该文件或等锁定期结束即可解锁。

服务器或 Docker 必须挂载持久化笔记目录；重新部署时保留目录。无持久化磁盘的平台不能直接使用此文件存储方案。Docker 示例：

```sh
docker build -t moxu-notes .
docker run -d --name moxu -p 127.0.0.1:3000:3000 --env-file .env.local -e NOTES_DIR=/app/data -v "$PWD/data:/app/data" moxu-notes
```

模型名由 `DEEPSEEK_MODEL` 配置。AI 每次调用最长 120 秒，失败或返回不完整时不覆盖正文。

## 检查

```sh
npm run typecheck
npm test
npm run build
```

纯浏览器才暴露的问题（编辑器渲染、装饰、运行时异常）用真机自检兜底：先 `npm run dev`，另开终端跑

```sh
npm run smoke                             # 只确认首页能渲染、没有运行时异常
SMOKE_NOTE="重要密码.md" npm run smoke      # 顺带打开一篇笔记检查内容
```

脚本用无头 Chrome 访问本地地址，会临时创建一个独立浏览器配置，不影响日常使用的浏览器。它会顺带点开侧栏「回收站」，确认面板能列出内容；这一步只看不改，不会动任何笔记。

## 暗色工作区与 AI 思考辅助

- 默认暗色；文件操作使用不占用文件树空间的悬浮菜单，支持点击外部和 Esc 关闭。
- 文件夹和笔记都能拖动：拖到同一层某一行之前/之后就是排序，拖到文件夹中间就是移进这个文件夹，拖到列表空白处就是移回笔记库根目录。顺序保存在 `.app/order.json`，刷新与其他设备读取相同顺序，不改变真实路径；文件夹菜单里的“上移/下移”保留为快捷方式。
- 悬浮菜单里的“重命名/移动”改成只重命名；移动一律用拖动。
- 删掉的笔记和文件夹进回收站：侧栏底部的「回收站」会显示数量和每一项的删除时间、原位置。恢复会放回删除前的位置，原位置已经有同名笔记时明确报错，不会覆盖现在的内容；图和标签这些配套元数据跟着一起回来。旧版本删除的项目没有记录原位置，也会出现在列表里，恢复时放回笔记库根目录。
- AI 自动选择决策依据图（材料 → 推理 → 决策）、流程图（步骤/条件/结果）或概念关系图。图的类型和选择理由会保存。旧版关系图仍可打开，重新生成后使用新结构。
- “评论改图”接收你的反馈并更新图，保留修改记录和上一版图；不会修改正文。
- 笔记只有编辑模式，没有阅读模式切换：输入时标题、加粗、列表、引用、代码、表格即时按样式渲染，光标所在行保留原始 Markdown 以便修改。
- 标题按层级分色（一级琥珀、二级灰绿、三级蓝、四级紫、五级青、六级灰），字号依次变小；嵌套列表的符号按层级用 •、◦、▪。
- 表格按 GFM 语法渲染成真正的表格（含对齐与单元格内的加粗、代码、链接）。点一下表格，它会就地展开成 Markdown 源码方便改，点到别处或按 Esc 收起。
- 标签和波浪线由自己添加：选中正文里的文字，在弹出的菜单里写下自己的标签（没有预设，最多 12 字），被选文字会带波浪线并显示标签；点标签可以换或去掉。标签保存在配套 JSON，不写进 Markdown。
- “和 AI 聊天”打开对话面板，每次发送都会带上当前这篇笔记的完整正文和最近的对话记录，问它内容、结构、说法上的问题。它只讨论、不代笔：可以说明哪里可以怎么改，但不会输出改写稿，也不会动正文。返回不完整或空内容时直接报错；旧版本里被 AI 改写过的笔记，顶栏“恢复原文”仍能退回上一条改前的内容。
- AI **没有联网查证能力**，不是事实认证。外部事实应视为待核实线索。图表达的是作者写出的理由，不表示这些理由已被验证。
- 所有新增元数据仍使用 JSON，不需要数据库。备份整个笔记目录即可。
